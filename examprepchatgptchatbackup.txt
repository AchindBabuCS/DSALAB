Q28 – Heap sort
Your answer: A (Min heap)

Incorrect

For ascending-order heap sort:

The largest element is at the root.

Heapify again.

4. Understanding heapify()
This is the most important function in Heap Sort.

Heapify ensures that the subtree rooted at a particular index satisfies the Max Heap property, assuming its child subtrees are already heaps.

The general logic:


text
heapify(arr, n, i)

    largest = i

    left = 2*i + 1
    right = 2*i + 2

    if left < n AND arr[left] > arr[largest]
        largest = left

    if right < n AND arr[right] > arr[largest]
        largest = right

    if largest != i
        swap arr[i] and arr[largest]

        heapify(arr, n, largest)
Notice that heapify is recursive!

If we swap the parent with one of its children, the affected subtree might no longer satisfy the heap property. So we recursively heapify that subtree.

Enqueue 30: 10, 20, 30

Rotate 20: 30, 10, 20

Now 30 is at the front!

Therefore, pop() removes 30.

Part 2: Queue using Stacks
Now we'll reverse the problem.

We want to implement a FIFO queue using LIFO stacks.

Method 1: Using two stacks (S1 and S2)
This is particularly important because it gives us an efficient queue implementation.

We'll make use of two stacks:

S1: Used for incoming elements.

S2: Used for outgoing elements.

Logic:

Enqueue(x)
Simply push the new element into S1.

Dequeue()
If S2 is not empty, pop from S2.

If S2 is empty, transfer all elements from S1 into S2 by repeatedly popping from S1 and pushing into S2.

Pop the top element from S2.

Why does this work?

Because transferring elements from one stack to another reverses their order.

dequeue() returns 10

The next dequeue returns 20, and the next returns 30.

Pseudocode

text
ENQUEUE(x):
    push(S1, x)


DEQUEUE():
    if S2 is empty:
        while S1 is not empty:
            push(S2, pop(S1))

    if S2 is empty:
        print "Queue Underflow"
    else:
        return pop(S2)

Method 2: Using one stack (recursion)
This is another interesting implementation.

We use recursion to simulate a second stack.

Logic
Enqueue(x):

Simply push x onto the stack.

Dequeue():

Pop the top element.

If the stack becomes empty, return that element.

Otherwise, recursively call dequeue().

After recursion returns, push the popped element back.

This removes the bottom-most element, which represents the oldest queue element.

Example
Stack initially:


text
Top → 30
       20
       10
Call dequeue():

Pop 30.

Pop 20.

Pop 10.

Stack becomes empty.

Return 10.

Push 20 back.

Push 30 back.

Final stack:


text
Top → 30
       20
       10
The value returned is 10, exactly as a queue should behave.

C implementation

c
int dequeue()
{
    int x = pop();

    if(top == 0)
    {
        return x;
    }

    int result = dequeue();

    push(x);

    return result;
}
This assumes pop() and push() are already implemented correctly and the queue is nonempty.

Part 4: What you should remember
Stack using queues

Make the newest element come to the front of the queue.

Queue using two stacks

Use recursion to reach and remove the bottom-most element.
